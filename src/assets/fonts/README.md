# Maple Mono NF CN

- Source: [Maple Mono v7.9](https://github.com/subframe7536/maple-font/releases/tag/v7.9)
- Archive: `MapleMono-NF-CN-unhinted.zip`
- Archive SHA-256: `ab88522932cf4015dffeaef6dedc59a22a5fefecdcc6e583d9fcd997da5b7cac`
- License: SIL Open Font License 1.1, reproduced unchanged in `LICENSE.txt` and in the application's font settings.

Regular, Bold, Italic and BoldItalic are converted from the official TTF files to WOFF2 using fontTools and Brotli. No glyphs, font names, metrics or OpenType features are removed or changed. Chinese characters and Nerd Font icons are retained; Chinese advance widths are checked to be twice the Latin advance widths.

The CSS family alias is `Gaze Maple Mono` to avoid relying on locally installed versions. Consolas is referenced by family name only and is not redistributed.
